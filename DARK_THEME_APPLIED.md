# Tema Oscuro y Visor de Fotos Mejorado ✅

## Cambios Aplicados

### 🌙 Tema Oscuro
- **Fondo**: Negro puro (#000000)
- **Colores**: Paleta oscura con azul iOS (#0A84FF)
- **Burbujas**: Azul para enviados, gris oscuro para recibidos
- **Texto**: Blanco y grises claros

### 📸 Visor de Fotos Premium

#### Nuevas Funcionalidades:
1. **Indicador de Zoom**: Muestra el porcentaje (100%, 150%, etc.)
2. **Botones de Control**:
   - 🔍- Zoom Out
   - ⭕ Reset (volver a 100%)
   - 🔍+ Zoom In
3. **Fondo Negro Puro**: Sin transparencias
4. **Animaciones Suaves**: Spring physics
5. **Feedback Visual**: Botones con hover y press effects

#### Controles:
- **Pinch**: Dos dedos para zoom
- **Double Tap**: Zoom rápido a 2.5x
- **Botones**: +/- para zoom preciso
- **Drag**: Mover imagen con zoom
- **Wheel**: Scroll para zoom (desktop)
