## 🚀 Cómo Instalar

### Opción 1: Desde Android Studio
1. Abre Android Studio
2. `File > Sync Now`
3. `Tools > Device Manager` - Crea emulador
4. Presiona `Ctrl + R` o ▶️
5. Selecciona el emulador
6. ¡La app se ejecutará! 🎉

### Opción 2: Instalar Manualmente
```bash
adb install ChatP2P/build/outputs/apk/debug/ChatP2P-debug.apk
```

## 🆘 Solución de Problemas

### La app no se abre
1. Abre Android Studio
2. `File > Invalidate Caches / Restart`
3. Espera a que se recargue
4. Intenta nuevamente

### No hay emulador
1. `Tools > Device Manager`
2. Crea un nuevo emulador (Pixel 6, Android 14)
3. Inicia el emulador
4. Intenta nuevamente

### La app se cierra
1. Abre Logcat (View > Tool Windows > Logcat)
2. Busca errores rojos
3. Reporta el error específico

### Firebase no sincroniza
1. Verifica tu conexión a internet
2. Abre la consola (F12 en navegador)
3. Busca errores de Firebase
