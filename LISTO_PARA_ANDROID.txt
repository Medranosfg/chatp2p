PARA EJECUTAR EN ANDROID STUDIO:
─────────────────────────────────

1. Cierra Android Studio completamente (Cmd + Q)

2. Abre Android Studio nuevamente

3. Sincroniza Gradle:
   File > Sync Now (o Cmd + Shift + I)

4. Invalida Caché:
   File > Invalidate Caches / Restart
   Selecciona: "Invalidate and Restart"

5. Configura un Emulador o Dispositivo:
   
   EMULADOR:
   - Tools > Device Manager
   - Crea nuevo emulador (Pixel 6, Android 14)
   - Inicia el emulador
   
   DISPOSITIVO FÍSICO:
   - Conecta via USB
   - Habilita "USB Debugging"

6. Ejecuta la App:
   - Presiona Ctrl + R o haz clic en ▶️
   - Selecciona emulador o dispositivo
   - ¡Debería ejecutarse! 🚀
