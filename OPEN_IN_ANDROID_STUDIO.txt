📱 PASOS PARA ABRIR EN ANDROID STUDIO:

1. DESCARGAR ANDROID STUDIO
   └─ Ve a: https://developer.android.com/studio
   └─ Descarga e instala

2. ABRIR ANDROID STUDIO
   └─ Abre la aplicación

3. ABRIR PROYECTO
   └─ Click en "Open"
   └─ Navega a esta carpeta (ChatP2P)
   └─ Selecciona y abre

4. ESPERAR SINCRONIZACIÓN
   └─ Gradle descargará dependencias (5-10 minutos)
   └─ Verás "Gradle sync finished" cuando esté listo

5. CONFIGURAR FIREBASE
   └─ Ve a: https://console.firebase.google.com/
   └─ Crea proyecto "ChatP2P"
   └─ Descarga google-services.json
   └─ Colócalo en: ChatP2P/app/google-services.json
   └─ Sincroniza Gradle nuevamente

6. EJECUTAR
   └─ Click en botón "Run" (play verde)
   └─ O presiona: Shift+F10 (Windows/Linux) o Ctrl+R (Mac)
   └─ Selecciona emulador o dispositivo

🐛 SOLUCIÓN DE PROBLEMAS:

Problema: "Gradle sync failed"
Solución: File → Invalidate Caches → Restart

Problema: "SDK not found"
Solución: File → Settings → Android SDK → Descargar API 30+

Problema: "App no se ejecuta"
Solución: Verifica que el emulador esté corriendo

Problema: "Firebase no funciona"
Solución: Verifica que google-services.json esté en app/
