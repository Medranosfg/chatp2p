# 🚀 ChatP2P Logo - Quick Start

## En 3 Pasos

### 1️⃣ Descargar Logos
```
Abre: export-logos.html
Haz clic en "Descargar SVG" o "Exportar PNG"
```

### 2️⃣ Exportar a PNG (si necesitas)
```bash
# App Store (1024x1024)
convert -background white -size 1024x1024 logo-appstore.svg -flatten logo-appstore-1024.png

# Play Store (512x512)
convert -background none -size 512x512 logo-appstore.svg logo-playstore-512.png
```

### 3️⃣ Subir a Tiendas
- **App Store**: Sigue APPSTORE_PLAYSTORE_GUIDE.md
- **Play Store**: Sigue APPSTORE_PLAYSTORE_GUIDE.md

---

## 📁 Archivos Principales

| Archivo | Tamaño | Uso |
|---------|--------|-----|
