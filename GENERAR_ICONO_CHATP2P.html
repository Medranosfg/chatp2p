📱 Cómo usar en Android Studio:

  1. Descarga el PNG haciendo clic en el botón
  2. En Android Studio: File → New → Image Asset
  3. Selecciona "Launcher Icons (Adaptive and Legacy)"
  4. En Foreground Layer → Image → selecciona el PNG descargado
  5. En Background Layer → Color → pon #000000
  6. Click Next → Finish
  7. Rebuild el proyecto
