🚀 PRUEBA EN ANDROID STUDIO:

1. Cierra Android Studio completamente
   └─ Espera 5 segundos

2. Abre Android Studio
   └─ Abre la aplicación

3. Abre el proyecto
   └─ File → Open
   └─ Selecciona: ChatP2P
   └─ Haz clic en "Open"

4. Espera a que sincronice
   └─ Verás "Gradle sync finished"

5. Verifica que aparezca el módulo "app"
   └─ En el árbol del proyecto (izquierda)
   └─ Debe decir "app" (no "<no module>")

6. Ejecuta la app
   └─ Haz clic en "Run" (botón play verde)
   └─ O presiona Shift+F10

7. Selecciona emulador o dispositivo
   └─ Elige uno de la lista
   └─ Haz clic en "OK"

8. ¡Listo!
   └─ La app se ejecutará
   └─ Verás la interfaz web

❌ SEÑALES DE PROBLEMA:

✗ Error: "Module not specified"
  └─ Solución: Cierra y reabre Android Studio

✗ Error: "Gradle sync failed"
  └─ Solución: File → Invalidate Caches → Restart

✗ Botón "Run" está gris (deshabilitado)
  └─ Solución: Espera a que Gradle termine de sincronizar

✗ No ves el módulo "app" en el árbol
  └─ Solución: File → Sync Project with Gradle Files

✗ Error: "SDK not found"
  └─ Solución: File → Settings → Android SDK → Descargar API 30+
