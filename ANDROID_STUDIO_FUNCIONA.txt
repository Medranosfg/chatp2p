🚀 PASOS PARA ABRIR EN ANDROID STUDIO:

1️⃣  ABRE ANDROID STUDIO
    └─ Abre la aplicación

2️⃣  ABRE EL PROYECTO
    └─ File → Open
    └─ Selecciona la carpeta ChatP2P
    └─ Haz clic en "Open"

3️⃣  ESPERA A QUE SINCRONICE
    └─ Gradle descargará dependencias (5-10 minutos)
    └─ Verás "Gradle sync finished" cuando esté listo

4️⃣  EJECUTA LA APP
    └─ Haz clic en "Run" (botón play verde)
    └─ O presiona Shift+F10
    └─ Selecciona emulador o dispositivo

5️⃣  ¡LISTO!
    └─ La app se abrirá en tu dispositivo/emulador
    └─ Verás la interfaz web con color verde brillante

🔧 CÓMO FUNCIONA:

1. MainActivity.java carga la app web en un WebView
2. WebView muestra index.html desde assets
3. La app web funciona normalmente
4. localStorage guarda datos en el dispositivo
5. Todo funciona sin necesidad de Firebase

═══════════════════════════════════════════════════════════════════════════

🎯 FUNCIONES PRINCIPALES:

✅ Crear Usuario
   └─ Ingresa nombre → Verás billetera → Continuar

✅ Ver Billetera
   └─ Haz clic en ⚙️ → Verás billetera en verde

✅ Copiar Billetera
   └─ Haz clic en "Copiar" → Se copia al portapapeles

✅ Cambiar Usuario
   └─ Haz clic en ⚙️ → "Cambiar Usuario" → Ingresa nuevo nombre

✅ Borrar Usuario
   └─ Haz clic en ⚙️ → "Borrar Usuario" → Confirma

✅ Chat P2P
   └─ Haz clic en + → Ingresa wallet → Inicia chat

💾 ALMACENAMIENTO:

localStorage (Dispositivo Android):
├─ walletAddress      → Tu dirección de billetera
├─ userHandle         → Tu nombre de usuario
├─ userData           → Datos del usuario
├─ chatsData          → Tus conversaciones
└─ messages           → Tus mensajes

Los datos se guardan en el dispositivo Android

🔧 SOLUCIÓN DE PROBLEMAS:

Problema: "Gradle sync failed"
Solución: File → Invalidate Caches → Restart

Problema: "SDK not found"
Solución: File → Settings → Android SDK → Descargar API 30+

Problema: "App no se ejecuta"
Solución: Verifica que el emulador esté corriendo

Problema: "No veo la app web"
Solución: Abre la consola (Logcat) → Verifica errores
