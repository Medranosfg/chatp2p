## Cómo Verificar

### En Navegador Web
1. Abre: `ChatP2P/index.html`
2. Limpia caché: `Cmd+Shift+Delete` (Mac) o `Ctrl+Shift+Delete` (Windows)
3. Recarga: `Cmd+R` o `Ctrl+R`

### En Android Studio
1. `File → Invalidate Caches → Invalidate and Restart`
2. `Build → Clean Project`
3. `Build → Rebuild Project`
4. `Run → Run 'app'`
