⚡ SOLUCIÓN RÁPIDA (3 PASOS):

═══════════════════════════════════════════════════════════════════════════

PASO 1️⃣  CIERRA ANDROID STUDIO
─────────────────────────────

1. Cierra todas las ventanas de Android Studio
2. Espera 5 segundos
3. Reabre Android Studio

═══════════════════════════════════════════════════════════════════════════

PASO 2️⃣  ABRE EL PROYECTO
─────────────────────────

1. Haz clic en "File" → "Open"
2. Navega a la carpeta: ChatP2P
3. Selecciona la carpeta raíz (donde está settings.gradle)
4. Haz clic en "Open"
5. Espera a que Gradle sincronice (5-10 minutos)
6. Verás "Gradle sync finished" cuando esté listo

═══════════════════════════════════════════════════════════════════════════

PASO 3️⃣  EJECUTA LA APP
──────────────────────

1. Haz clic en el botón "Run" (play verde)
   O presiona: Shift+F10

2. Selecciona emulador o dispositivo
   └─ Si no ves ninguno, abre Android Virtual Device Manager
   └─ Crea un nuevo emulador
   └─ Inicia el emulador
   └─ Intenta ejecutar de nuevo

3. Haz clic en "OK"

4. ¡Listo! La app se ejecutará

🎯 FUNCIONES PRINCIPALES:

1. Crear Usuario
   └─ Ingresa nombre → Verás billetera → Continuar

2. Ver Billetera
   └─ Haz clic en ⚙️ → Verás billetera en verde

3. Copiar Billetera
   └─ Haz clic en "Copiar" → Se copia al portapapeles

4. Cambiar Usuario
   └─ Haz clic en ⚙️ → "Cambiar Usuario" → Ingresa nuevo nombre

5. Borrar Usuario
   └─ Haz clic en ⚙️ → "Borrar Usuario" → Confirma

6. Chat P2P
   └─ Haz clic en + → Ingresa wallet → Inicia chat

🚨 SI NO FUNCIONA:

Problema: "Module not specified"
Solución: Cierra y reabre Android Studio

Problema: "Gradle sync failed"
Solución: File → Invalidate Caches → Restart

Problema: Botón "Run" está gris
Solución: Espera a que Gradle termine de sincronizar

Problema: No ves el módulo "app"
Solución: File → Sync Project with Gradle Files

Problema: "SDK not found"
Solución: File → Settings → Android SDK → Descargar API 30+
